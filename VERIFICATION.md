# Фактическая проверка

Среда: Windows PowerShell, Python 3.14.3, Node.js 24.14.0, npm 11.9.0.

| Проверка | Результат |
|---|---|
| Backend `python -m pytest` | 48 passed |
| Frontend `npm run typecheck` | Успешно, ошибок TypeScript нет |
| Frontend `npm run build` | Успешная production-сборка Vite |
| Playwright `npm run test:e2e` | 2 passed; полный сценарий и сохранение формы при ошибке |
| SQLite seed и каталог | 5 задач, рейтинги 100 / 85 / 65 / 45 / 20 |
| Живой внешний LLM | Не вызывался; ключ не предоставлен |

Backend покрывает рейтинг и границы уровней, заглушки и отсутствующие материалы,
снимки и конфликт версии, фильтры и сортировку, низкорейтинговые задачи, несколько
принятых команд, отсутствие лимита в пять откликов, права и URL, идемпотентность
seed и баллов, сквозной путь. AI-проверки используют настоящий код HTTP-адаптера
с mock-ответами на успешный запрос, timeout, HTTP-ошибку, malformed JSON,
неверную схему и обрезанный ответ. Поддержка конкретной внешней модели без ключа
не подтверждена.

В первом запуске pytest: предупреждение Starlette об устаревающем использовании
httpx в TestClient (тесты работают), а также предупреждение о недоступности pytest-cache
в песочнице. Необязательный cacheprovider отключён в pytest.ini. На production это не влияет. Vite сначала встретил `spawn EPERM` в
песочнице; повторная сборка после разрешения запуска дочерних процессов прошла.
macOS/Linux в этой среде не запускались. Публичного деплоя нет.

Браузер: Google Chrome, headless, 1440×1000. Проверены создание и уточнение задачи,
неизвестные данные, подтверждение 20 баллов, ручное дополнение до 100, публикация,
смена профилей, отправка предложения, принятие, отправка этапа и +10 после подтверждения.
Ошибок JavaScript на этом пути нет. Второй тест проверяет фильтр «Черновик», очистку
фильтров и сохранение текста/восстановление кнопки после серверной ошибки.
В первом прогоне второй тест имел неверный селектор label у select; он исправлен на
доступную роль combobox, после чего оба теста прошли. Скриншоты главной, каталога
и подтверждения результата созданы; главная и каталог визуально просмотрены.

## Проверка после обновления визуального стиля

Светлый интерфейс заменён тёмной темой с верхней навигацией и локальными
графическими обложками. Повторно выполнены `npm run typecheck`, `npm run build`
и `npm run test:e2e`: проверка типов и сборка успешны, **2 браузерных теста прошли**.
Исходный сквозной сценарий сохранился, ошибок JavaScript в нём нет.
Визуально проверены главная, каталог и редактор при ширине 1440px, каталог при
390px с включённым reduced motion. Скриншоты: `frontend/test-results/home.png`,
`catalog.png`, `editor.png`, `catalog-mobile.png`. Backend-код этим обновлением
не менялся; 48 backend-тестов относятся к предыдущей проверке.
