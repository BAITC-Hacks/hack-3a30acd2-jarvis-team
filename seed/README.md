# Синтетические данные

Все организации, команды, контакты и результаты вымышлены. Ссылки example.org —
демонстрационные заглушки, а не готовые чужие прототипы. Они явно отмечены в UI.
Пять исходных описаний и пять полных по ключам карточек находятся в отдельных JSON-файлах.
Результат human-confirmed карточек задан автором демонстрации, а не сгенерирован AI.

Пересоздание файлов fixtures: `python seed/build_fixtures.py` из корня.
Загрузка в БД: `python -m app.seed` из backend. Баллы рассчитываются серверной функцией.
Рейтинги этих fixtures: 100, 85, 65, 20, 45 — все четыре уровня.
