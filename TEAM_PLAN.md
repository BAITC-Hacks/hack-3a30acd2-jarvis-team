# План команды на 300 минут

| Время | Даурен · backend | Алишер · frontend | Третий участник · AI, данные, качество |
|---|---|---|---|
| 0–30 | Вместе: TaskCard, состояния, API_CONTRACT, demo headers, версия | Вместе: маршруты и DTO | Вместе: рубрика и критерии демо |
| 30–90 | SQLite, модели, роли, CRUD, снимки и confirm | Каркас React, профили, каталог, API-клиент | Fallback, стабильные вопросы, JSON-наборы seed |
| 90–150 | Рейтинг, публикация, предложения и решения | Конструктор, редактирование, источники, рейтинг | Prompts, HTTP-адаптер, evidence, fallback ошибок |
| 150–195 | Этапы, идемпотентные баллы, ошибки | Кабинеты, сравнение предложений, отправка результата | pytest рейтинга, AI, seed и прав |
| 195–225 | Полный путь вместе, согласование ошибок и версий | Интеграция реальных серверных ответов | Сквозной API-тест, затем браузерный прогон |
| 225–270 | Исправления транзакций и конфликтов | Typecheck/build, состояния ошибок и адаптивность | Негативные проверки, результаты тестов |
| 270–300 | README запуска и ограничения БД | Проверка показательных экранов | DEMO_SCRIPT, подготовленные ответы и общая репетиция |

Границы файлов позволяют работать параллельно: Даурен владеет `backend/app/api`,
`models.py`, `database.py`, `services/scoring.py`; Алишер — `frontend/src`;
третий участник — `services/ai`, `prompts`, `seed`, `tests`, демонстрационные документы.
`schemas.py`, `frontend/src/types/index.ts` и `API_CONTRACT.md` меняются согласованно.

Точки интеграции: `AIService.run` возвращает типизированный результат и mode/message;
`calculate_score` — чистая функция, её используют confirm, preview и seed;
все frontend-запросы идут через один клиент с demo headers.

Готовность к сдаче: путь от описания до +10 команде воспроизводится без ключа;
публичный снимок сохраняется при правке; низкий рейтинг не скрывает задачу;
можно выбрать две команды; нет фиктивного API и кнопок без действий;
фактические проверки записаны в VERIFICATION.md.
