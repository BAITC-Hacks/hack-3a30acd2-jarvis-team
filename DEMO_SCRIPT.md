# Пятиминутная демонстрация TaskUp AI

Перед показом запустить backend, frontend и отдельную команду seed из README.
Проверить http://127.0.0.1:5173. Ключ не нужен; оставить `LLM_PROVIDER=rule_based`.
Все ответы ниже — подготовленные сведения **вымышленного представителя бизнеса**.
Их вводит человек. Они не возникают в карточке автоматически.

## 0:00–0:30 · Выбор профиля и слабый запрос

На стартовой странице выбрать «Я представитель бизнеса» → «Учебный центр „Орбита“» →
«Перейти в кабинет» → «Создать задачу». Отрасль — «Образование».

Вставить:

> Мы небольшой учебный центр. Сейчас отмечаем оплату курсов вручную и иногда теряем сведения. Хотим навести порядок с оплатами.

Нажать «Уточнить с помощником». Обратить внимание на **локальный резервный режим**:
это шаблоны и консервативное извлечение, а не ответ подключённой нейросети.

## 0:30–1:15 · Вопросы и минимальная карточка

Помощник задаст пять вопросов: название, пользователи, материалы, результат и критерии.
В названии указать **«Оплаты курсов — демонстрация»**. Для остальных нажать
«Пока не знаю». Нажать «Сформировать карточку».

Показать исходное описание и ответы: неизвестные поля пусты, нет придуманных CSV,
контактов или сроков. Контекст и потребность извлечены с цитатами. Название дано человеком.
Нажать «К подтверждению», поставить отметку проверки, «Подтвердить сведения».

Ожидаемый фактический расчёт: контекст 10 + потребность 10 = **20/100, «Черновик»**.
Название не добавляет баллов. Уровень «Черновик» допускает публикацию — его не следует
путать с неподтверждённой рабочей версией. При необходимости показать опубликованный
пример «Быстрая инвентаризация магазина» с 20 баллами в другой вкладке.

## 1:15–2:45 · Человеческие уточнения и рост готовности

Нажать «Вернуться к карточке». Вставить ответы в соответствующие редактируемые поля.
Контекст и потребность уже есть, их можно оставить.

| Поле | Подготовленный ответ |
|---|---|
| Пользователи | Два администратора учебного центра. |
| Данные и материалы | Синтетический CSV: 100 оплат, курс, дата, сумма, статус. |
| Источник данных | Представитель передаст обезличенный CSV при старте. |
| Ожидаемый результат | Веб-прототип реестра с поиском и статусом оплаты. |
| Срок | Три недели с момента начала. |
| Ограничения | Только синтетические данные; без подключения банков. |
| Контакт | orbit@example.org (вымышленный контакт). |
| Формат взаимодействия | Онлайн-встреча раз в неделю. |
| Процесс обратной связи | Представитель проверяет промежуточный результат по пятницам. |

В «Критерии успеха» нажать «Добавить критерий»:

- Критерий: **Сохранность записей при импорте**.
- Ожидаемое значение: **100 из 100 строк доступны в реестре**.
- Способ проверки: **Сверить количество и суммы с контрольным CSV**.

Показать «Будет после подтверждения»: **100/100**. Официальная оценка пока **20**.
Можно нажать «Сохранить черновик»: оценка публичной версии от этого не меняется.
Нажать «К подтверждению», проверить сведения, отметить checkbox, подтвердить.
Фактическое изменение: **+80**, итог **100/100, «Приоритетная»**.
Нажать «Опубликовать в каталоге», затем открыть карточку и перейти в общий каталог.
Карточка окажется в группе задач с 100 баллами; старшая публикация с равным рейтингом
будет выше по стабильной сортировке.

## 2:45–3:35 · Команда сама выбирает задачу

«Сменить профиль» в правой верхней части → «Я студенческая команда» → «Импульс» →
«Открыть каталог». Найти «Оплаты курсов — демонстрация», открыть и заполнить:

| Поле | Значение |
|---|---|
| Идея | Реестр оплат с CSV-импортом и поиском по курсу. |
| План | Уточнить сценарий администратора, собрать прототип, проверить импорт на контрольном CSV. |
| Срок | 3 недели. |
| Ссылка на прототип | Оставить пустой: готового прототипа пока нет. |

Отправить предложение. Показать статус в кабинете команды. Баллы команды — **0**.

## 3:35–4:15 · Ручной выбор бизнеса

Сменить профиль обратно на бизнес «Орбита». В «Мои задачи» открыть предложения
созданной задачи, нажать «Выбрать команду». Отметить: AI не выбирает исполнителя.
Для сравнения открыть seed-задачу «Порядок в оплатах учебного центра» с двумя
предложениями: можно принять обе команды, отклонить каждую или пока не принимать ни одну.

## 4:15–5:00 · Подтверждённый результат

Вернуться к команде «Импульс». Для принятого предложения в кабинете заполнить «Что сделано»:

> Для демонстрации подготовлен прототип реестра. На синтетическом CSV импортированы 100 строк и сверены суммы. Представителю показаны поиск и изменение статуса оплаты.

Это учебный пример результата; не заявлять, что реальный проект уже выполнен.
Ссылку оставить пустой. Отправить результат: статус **«На проверке · 0 баллов»**.
Перейти к бизнесу → предложения задачи → прочитать результат → «Подтвердить результат».
Команде начислено **10 баллов**. Повторное подтверждение через API не удвоит сумму.

Финальная фраза: «Бизнес получает видимость за ясность задачи; команда — баллы за
подтверждённый результат. Неизвестные факты остаются неизвестными, решения принимает человек».

## Если что-то пошло не так

- Нет сети или ключа: локальный режим обеспечивает тот же обязательный сценарий.
- Ошибка API: текст остаётся в форме; после восстановления сервера повторить действие.
- Конфликт версии: сохранить свой текст отдельно и заново открыть карточку из кабинета.
- Для чистой репетиции использовать **только явный** `python -m app.seed --reset --yes`.
